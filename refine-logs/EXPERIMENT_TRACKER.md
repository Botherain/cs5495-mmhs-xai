## 结果摘要（2026-11-13）

**P0 闸门。** 5 头 macro ROC 0.7759（发布 0.7832，落在 ±0.03 容差内），macro F1 0.5660（门槛 0.539），判 **REPRODUCED**，无需在 val 上重扫阈值。剔除 religion 后的 4 个可用头 macro AUC 0.8185 / F1 0.6536，作为全部分析的目标函数。

**P1.3 忠实性（499 条选择集）。** 文本 LIME AOPC +0.0620、KernelSHAP +0.0606，均过 0.01 门槛且远高于随机 +0.0179；occlusion +0.0013，低于随机。图像仅 occlusion +0.0013 过 0.001 门槛，Grad-CAM −0.0010、IG −0.0003、Score-CAM −0.0001 全部 ≤0。赢家：文本 LIME、图像 occlusion（`p1_decision.json`）。

**P1.4 随机化闸门（n=100）。** 文本塔三方法 ρ_depth=−0.90、r_full 0.06–0.09，全部通过；图像塔只有 occlusion 通过（ρ_depth=−1.00、r_full=−0.04），Grad-CAM r_full=+0.68、IG +0.33、Score-CAM +0.23 —— 这三者的归因在视觉塔被完全随机化后仍与训练模型高度一致，说明它们描述的是架构而非学到的函数。这是对图像侧梯度方法的第二个独立否定。

**P1.5 稳定性。** LIME 最差一对 ρ=0.663 / top-10% 重叠 0.798，KernelSHAP 0.853 / 0.872；四种图像方法在 5% 像素噪声下 ρ≥0.995。全部过 0.5 门槛。

**P1.6 方法间一致性（499）。** LIME–KernelSHAP ρ=0.51 / 重叠 0.67；occlusion–Grad-CAM ρ=−0.33 / 重叠 0.07（方向相反）；Score-CAM 与其余几乎无关（|ρ|≤0.02）。

**P2 模态 Shapley（3,000）。** φ_T 均值 +0.0467、中位 +0.0152（54.6% 为正）；φ_I 均值 +0.0014、中位 −0.0004（56.5% 为负）；文本主导 99.43%；完备性误差 6.9e−08；门控 ρ=0.449（p=5.1e−149）但符号一致率仅 86.2%；交互项均值 −0.0007。单元级删除曲线：文本 +0.0463、图像 +0.0010、随机 −0.0032。

**P5 人机一致性（3,000）。** ρ=−0.102，单侧 p=1.06e−08。方向正确、显著，但 |ρ|<0.2，**未过门槛**，按未通过报告。分桶 φ_T：全一致 +0.0189、部分一致 +0.0501、全不一致 +0.0896；φ_I 三桶基本持平（+0.0012/+0.0014/+0.0014）。

**偏差记录。** 分析集与选择集都取自 test split（val 图像未下载），因此 P6 的 head 重训在 test 3,000 内做分层 2,000/1,000 划分，而不是计划里的 val→test 迁移；P0.6 的单样本工程核对未单独落盘，等价检查（掩码干预、池化位置）内嵌在 notebook §2 的演示单元里。

**已知事故。** `attribution.content_positions` 对 `(1,77)` 掩码返回空列表，导致第一轮 P1.3 中 LIME / KernelSHAP / 随机三者的 AOPC 完全相同；修复后删除 `p1_faithfulness.jsonl` 重跑。另有两段长任务在后台静默退出（无 traceback、无系统事件），改为前台 + faulthandler 并逐样本落盘后稳定。

## 偏差记录（补充）

**概念集来源。** 计划 D5 要求"人工筛选（按图像内容），由本人完成"，取样顺序为 ① 分析集外 test 图 → ② val → ③ 分析集内补图。实际 `p3_concepts.py` 用三个检测器自动生成（EasyOCR 框 / OpenCV Haar / 颜色熵十分位），且 1,824 张中 1,563 张取自分析集，两级顺序都被违反。事后用 600 张分层抽检量化了每个线索的敏感度/特异度，并把它写进报告 §6 与 §11，但没有重建人工概念集。

**P4.2 定性案例未做。** 40 条（20 翻转 + 20 对照）人工检视没有执行，§7 只报统计量。

**P7 空白基线。** SigLIP2 的两个 φ 均值均为负（−0.0091 / −0.0097），说明空白基线在该 checkpoint 上高于真实输入，绝对值不可解释；只使用主导率与量级排序，报告 §10 已注明。

## 审核记录（2026-11-14，提交前自查）

逐条核对了理论偏差与代码漏洞，三处实质问题已修复并重跑，其余核对通过。

**1. P3.1 对照面积错误（已修，重跑）。** 等面积对照用"框面积之和"定边长，而观测统计量用的是框的
**并集**覆盖率；框重叠时和大于并集（均值比 0.955，46% 样本低于 0.98，最低 0.68），对照因此偏大、
超额偏负。改为并集面积后：超额 −1.16 pp → **−0.48 pp**（p=2.1e−07），并保留和面积版本 −1.13 pp
作敏感性。结论方向不变（仍远低于 +15 pp 门槛且为负）。

**2. P5 未实现预登记口径（已修，重跑）。** 原实现跑全样本相关（ρ=−0.102）。预登记要求：仅
"≥1 人给出可用仇恨标签（religion 不计）"的子集，且做控制偏相关。修正后主分析 n=2,202：
ρ=**−0.071**（单侧 p=4.6e−4），控制可用票数与 v(T,I) 四分位后 **−0.045**（p=0.017）；
全样本在同样控制下塌到 −0.008。§9 的"单调桶趋势"在子集内不成立（φ_T 0.085 / 0.050 / 0.090），
原叙事作废，改为"效应大部分是目标水平的混杂"。

**3. P6 目标函数类权重颠倒（已修，重跑）。** BCE 的 `pos_weight` 写成了 n_pos/n_neg（torch 语义是
乘在正类上，平衡应为 n_neg/n_pos），稀有头被进一步降权，两臂 eval F1 只有 ~0.38。修正后：
arm2 0.461 / 图像份额 22.7%，arm3 0.483 / 11.3%，Δ 份额 **−11.4 pp**、ΔF1 **+0.022**——dropout 臂
反而更准。150/400/800 三个预算下符号一致（−6.8 / −11.4 / −8.6 pp；F1 +2.6 / +2.2 / +2.1 pp）。

**核对通过（未改）。** CLIP 融合路径与自身 forward 逐样本最大差 0.0；SigLIP2 同（0.0）；
