# Experiment Plan

**Problem**: 多模态仇恨检测模型（MMHS150K + CLIP ViT-B/32 门控融合）在推理时是否真的使用图像模态，以及哪些 XAI 方法在该设定下忠实。
**Method Thesis**: 用"先选忠实方法、再做模态级联盟分解"的顺序，把每条预测的功劳精确拆给文本与图像，并用删除曲线、门控范数、跨 checkpoint 复现三重证据固定结论。
**Date**: 2026-11-12

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |
|-------|----------------|-----------------------------|---------------|
| **C1** 模型预测由文本主导；图像在相当比例样本上贡献≈0 甚至为负 | 直接回答"多模态模型是否只是文本分类器"，是整份报告的结论 | 3,000 条样本的 φ_T/φ_I 分布 + 模态级删除曲线显著低于随机 + 门控范数比与 φ 比值正相关 + SigLIP2 复现 | B2, B3 |
| **C2** 多模态设定下，梯度类解释（Grad-CAM）通不过参数随机化检验，遮挡/Shapley 类更忠实 | 构成"先选方法"的硬性前置，同时是方法论贡献 | 7 方法 × 5 指标矩阵；Grad-CAM 的 sanity-check 一致性下降幅度显著小于遮挡类 | B2 |
| **C3** 模型置信度与人类标注一致性错配（分歧样本上更自信） | 回答课程建议问题"模型是否像人"，且 MMHS150K 自带 3 标注者 | 一致性三档（全体一致/部分分歧/全分歧）上的置信度分布差异检验 | B4 |
| **C4（辅助）** 按 XAI 结果做模态 dropout 重训融合头，可提升"文本中性+图像有毒"子集 | 回答"基于 XAI 的改进建议" | 该子集召回上升且总体 macro-F1 不下降（配对检验） | B5 |

**Anti-claims to rule out**

- **A1** φ_T 主导是空白输入基线的假象 → B3 加入结构化消融（flag 置零）口径复算，两口径结论方向一致。
- **A2** 结论只在单个 checkpoint 上成立 → B2/B3 在 SigLIP2 checkpoint 上复现关键量。
- **A3** 结论由预处理造成（77 token 截断、URL/mention 保留） → B1 做预处理消融：保留 vs 剥除 URL/mention，比较 φ 分布。

## Experiment Blocks

### Block 1: 数据与基线（M0）

- Claim tested: 后续所有数字建立在一个可复现的基线上（不直接支撑 C1–C4，但缺此块全部失效）。
- Why this block exists: 3 处已知不确定：checkpoint 能否复现自报 macro-F1、图像能否下载完整、二值化口径影响多大。
- Dataset / split: 官方 `splits/train_ids.txt`、`val_ids.txt`、`test_ids.txt`；`MMHS150K_GT.json` 的 `labels`（3 元数组）与 `img_txt/`。
- Compared systems: 无（基线复现）。
- Metrics: macro-F1、per-head ROC-AUC、hate 占比、三人完全一致比例、三人全分歧比例。
- Setup details: 图像 224×224 + CLIP 归一化；文本 `max_length=77`；输出用 sigmoid 概率，不取 argmax；目标函数 = 4 头均值（§5.3 口径）。
- Success criterion: 复现 macro-F1 0.569±0.03、macro ROC-AUC 0.783±0.03；测试子集 ≥3,000 条。
- Failure interpretation: 复现失败（差距 >0.05）→ 换 SigLIP2 checkpoint；两者都失败 → 用 CLIP 零样本基线，并在报告中说明"审计对象变更"。
- Table / figure target: 报告 §3 基线表（一行复现结果 + 发布方自报值）。
- Priority: **MUST-RUN**

### Block 2: 忠实度横评（M1）

- Claim tested: C2。
- Why this block exists: 课程硬性要求"先选方法"；同时决定后续分析用哪个文本侧、哪个图像侧方法。
- Dataset / split: 500 条分层子集（按标签 × 标注一致性），固定种子。
- Compared systems: 文本 LIME / KernelSHAP / Occlusion；图像 Grad-CAM / IG / Occlusion / Score-CAM。
- Metrics: 门槛——参数随机化 sanity check（逐层随机化后归因与原归因的 Spearman）、种子/噪声稳定性；主排序——AOPC（删除+插入）；佐证——comprehensiveness/sufficiency、方法间 top-k 重叠与排序相关。
- Setup details: 删除=替换（文本→padding，图像→均值色）；每条样本按目标函数定标量；插入从空白输入逐步加回。
- Success criterion: 每个模态各产出一个赢家，且赢家在 sanity check 中的归因衰减显著（p<0.05）；排序差异具备统计显著性（bootstrap 95% CI 不重叠）。
- Failure interpretation: 若所有方法都过不了 sanity check → 报告"该模型上无可用的梯度类解释"，改用遮挡族作为唯一证据，并把该现象写成发现。
- Table / figure target: 报告主表 1（方法 × 指标矩阵）、图 1（AOPC 曲线族）。
- Priority: **MUST-RUN**

### Block 3: 模态分解（M2）

- Claim tested: C1；同时检验 A1、A2、A3。
- Why this block exists: 项目核心。
- Dataset / split: 3,000 条分层子集。
- Compared systems: 4 个联盟 v(∅)、v(T)、v(I)、v(T,I)；两种基线（空白输入 / flag 置零）。
- Metrics: φ_T、φ_I、交互指数 I = v(T,I) − v(T) − v(I) + v(∅)；完备性误差；模态级删除曲线 AOPC；与门控范数比的 Spearman；与文本侧赢家 token 归因总和的 Spearman。
- Setup details: 每次 Coalition 一次前向即得全部 5 头；目标函数固定；argmax 头只用于单例叙述。
- Success criterion: 完备性误差 <1e−6；真实删除曲线显著低于随机（配对 t，n=3,000）；φ_I≈0 的样本比例给出点估计与 bootstrap CI；SigLIP2 上方向一致。
- Failure interpretation: 若 φ_I 与门控比 ρ≈0，说明门控学到的东西与实际影响脱耦，作为失败模式写入，不改结论方向。
- Table / figure target: 主图 2（φ_T vs φ_I 散点，按人类一致性着色）、主表 2（模态贡献分位数）。
- Priority: **MUST-RUN**

### Block 4: 图像分支诊断 + 人类一致性（M3）

- Claim tested: C3；为 C1 提供机制解释。
- Why this block exists: 回答"图像分支在算什么"，并把 3 标注者数据转成人类基线。
- Dataset / split: 40 条定性案例（含图内文字、反讽、回收侮辱词）；3,000 条做一致性分层统计。
- Compared systems: 归因热图 × 人脸框/OCR 文字框能量占比；抹掉图内文字 vs 抹掉背景；PFI（分组置换）；PDP（按文本长度）；TCAV（3 概念 × 20 随机方向）。
- Metrics: 能量占比、φ_I 变化量、PFI null 分位、PDP 置信带、TCAV 的 p 值与 split-half 相关、三档一致性上的置信度均值与方差。
- Success criterion: TCAV p<0.05 且 split-half >0.5；PFI 落在 null 95% 分位外；一致性三档的置信度差异显著（Kruskal-Wallis）。
- Failure interpretation: TCAV 不显著 → 报告"无可辨识概念敏感度"，不作为 C1 证据；一致性差异不显著 → 报告"置信度与人类分歧无关"，同样是有价值的负面结果。
- Table / figure target: 主图 3（OCR vs 背景遮挡对比）、附表 2（全局/概念方法验证）。
- Priority: **MUST-RUN**

### Block 5: 失败模式与改进验证（M4）

- Claim tested: C4。
- Why this block exists: 课程建议问题"what improvements would you suggest"，且只提建议不验证只能拿部分分。
- Dataset / split: 3,000 条（缓存 CLIP 特征）；"文本中性+图像有毒"子集单独统计。
- Compared systems: 冻结特征 + 融合头基线；同结构 + 模态 dropout（p=0.3）；随机遮 top-k 归因单元 vs 随机遮同量。
- Metrics: 目标子集召回、总体 macro-F1、φ_I 均值变化、翻转率差。
- Setup details: 编码器冻结，仅训融合头与 5 个头；AdamW，lr 1e-3，10 epoch，3 seeds。
- Success criterion: 子集召回上升且总体 macro-F1 下降 ≤0.01（配对检验 p<0.05）；φ_I 均值上升。
- Failure interpretation: 若 recall 上升但 macro-F1 明显下降 → 报告"去偏存在精度代价"，给出权衡曲线，不强行宣称改进。
- Table / figure target: 主表 3（改进前后对比）、图 4（翻转率对比）。
- Priority: **MUST-RUN**（若 21–22 Nov 未完成，仅报告建议，不写入结论）

## Compute and Data Budget

- Total estimated GPU-hours: 约 3 h（含调试），核心跑批 < 1 h。
- Data preparation needs: 6 GB 压缩包 → 解压后约 7 GB；另有 HF 权重 613 MB + 基座 CLIP 600 MB（已缓存）。
- Human evaluation needs: 无新标注；人类基线取自数据集自带的 3 标注者。TCAV 概念集需人工抽查约 200 条 × 3 概念。
- Biggest bottleneck: 数据下载与图像完整性核对（推文删除导致的缺图），以及 14–17 Nov 的方法实现与调试。

## Risks and Mitigations

- **图像大量缺失**：先用 `img_resized/` 实际存在的文件统计覆盖率；缺图样本从三个子集里剔除并在报告中报告剔除比例。
- **标签噪声主导结论**：所有一致性分析按三档分层；主结论只在"三人一致"子集上复核一遍。
- **Grad-CAM 在 ViT-B/32 上只有 7×7**：图像侧精确分解改用 SLIC 超像素（10–20 区域），CAM 只作定性展示。
- **77 token 截断**：统计被截断样本比例；B1 做保留/剥除 URL 的消融。
- **checkpoint 不稳定**：主模型失败即切 SigLIP2，两者都失败切 CLIP 零样本，并同步改写报告对象描述。
